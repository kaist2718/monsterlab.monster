**공통 인프라 자산 (경쟁 우위)**

- **빌드 없는 정적 사이트 파이프라인**: 배포 비용이 사실상 0에 가깝고, 서비스 하나를 여는 데 필요한 공수가 극히 작음.
- **자체 호스팅 방문 분석**: 쿠키 없음 · IP 무저장 → 동의 배너 불필요. 프라이버시 규제 리스크가 큰 유럽·국내 환경에서 **제품 스토리이자 법적 안전장치**.
- **검증 문화(`smoke-test.js`)**: 배포 전 기능·i18n·폼 전송을 자동 검증. 1인 팀의 "실수 비용"을 크게 줄임.
- **.monster 패밀리 크로스 프로모션**: 홈 히어로 캐러셀이 3개 서비스를 순환 노출하고, 슬라이드·점·설명 버튼이 각 서비스 설명으로 직접 연결됨.

## 2. 시장 환경 분석

### 2.1 영어 학습 (핵심 시장)

- 국내 토익 응시자는 **연간 약 180만~200만 명대**, 1인당 연평균 응시 횟수는 **1.8회** (한국TOEIC위원회, 2023 조사). 2025년 정기시험 평균 성적은 **686.2점**이며 응시자의 **45.1%가 21~25세** (한국TOEIC위원회 발표, 2026-03 보도).
- **시사점 ①**: 시험 자체는 반복 소비 시장이다. "한 번의 시험 대비"가 아니라 **"시험 사이의 학습 루틴"**을 잡는 제품이 재방문을 만든다.
- **시사점 ②**: 주 타깃(20대 초중반)은 가격에 민감하고 모바일·짧은 세션을 선호 → 무료 코어 + 저가 구독(월 5천 원대 이하) 구조가 적합.
- **시사점 ③**: 토익만으로는 계절성(취업 시즌)이 강하다. 비시험기 수요를 흡수할 **일상 영어 콘텐츠(engmon)와의 연결**이 방파제 역할.

### 2.2 에듀테크 · 디지털 교육 콘텐츠

- 한국 에듀테크 시장: **2024년 약 47.5억 달러 → 2033년 약 99.8억 달러(연평균 7.7%)** (IMARC Group, 2026-01). 글로벌 에듀테크는 **2025년 약 4,040억 달러** 규모로 전망(삼일PwC, 2024-02).
- 디지털 교육 콘텐츠 시장은 **2025~2034년 연평균 15%대** 성장이 전망됨(MarketResearchFuture).
- **시사점**: 시장은 커지지만 대형 자본이 들어오는 영역이기도 하다. **"대형 플랫폼이 하기 싫은 작은 지점"**(특정 시험의 오답 관리, 특정 텍스트의 대역 판본)을 선점하는 전략이 유효.

### 2.3 웰니스 · 마음챙김 (buddha 확장 시장)

- 명상 관리 앱 시장은 **2025년 약 22억 달러 → 2033년 약 70억 달러**로 전망(Grand View Research). 명상·멘탈 웰니스 앱 시장은 **2029년 70억 달러 돌파**가 예상됨(Statista).
- **시사점**: buddha.monster는 콘텐츠(법구경 대역)와 습관 장치(오늘의 법구·수련 레벨·스트릭)를 이미 보유하고 있다. 여기에 **"하루 3분 루틴"**만 더하면 웰니스 앱 카테고리로 확장할 수 있으며, 이는 광고가 아닌 **구독형** 수익 모델과 잘 맞는다.

| 항목 | 내용 |
| --- | --- |
| 컨셉 | toeic의 오답 표현 + engmon의 주간 표현을 하나의 단어장에 모아, **간격 반복(Spaced Repetition)으로 복습**하는 서비스 |

| 기존 자산 활용 | engmon의 단어장·복습 카드 코드, toeic의 오답 데이터 구조, 자체 분석 서버 |
| MVP 범위 | toeic·engmon 표현을 같은 형식으로 모으는 저장소 + 복습 화면 1종 (계정 없이 브라우저 저장으로 시작) |

**운영 원칙**

1. 한 번에 **신규 서비스 1개 + 개선 1개**만 진행 (병렬 실험 금지).
2. 모든 신규 사업은 **기존 서비스의 자산(콘텐츠·코드·사용자)을 최소 1개 재사용**해야 함.
3. 8주 판정 원칙: 지표 목표 미달 시 **감정이 아니라 기준으로** 종료.

## 6. 수익화 전략

### 6.1 모델 구조

```
무료 코어 (트래픽·습관·신뢰)
  ├─ 유료 워크북/인쇄물 (일회성, engmon — 현재 유일 매출원)
  ├─ 프리미엄 구독 (월 ₩4,900~9,900 — wordbook·mind)
  └─ B2B 라이선스 (학원·대학 — Phase 3 검토)
```

### 6.2 가격 정책 원칙

1. **무료 기능은 "완전히 무료"** — buddha의 무가입·무광고 약속은 브랜드 자산이므로 유지.
2. 구독 가격은 **커피 한 잔 이하(월 5천 원대)** 에서 시작해 가치 검증 후 인상.
3. 연간 결제는 2개월 무료 수준의 인센티브로 설정.
4. **교육 면세 요건**(원격평생교육시설 등록 등)은 toeic 유료화 전 반드시 결정 — 사업자등록 보고서 §4.3 참조.

### 6.3 가정 검증 계획

| 가정 | 검증 방법 | 판정 시점 |
| --- | --- | --- |
| 사용자는 크로스 서비스 단어장에 비용을 낼 의향이 있다 | 무료 → 프리미엄 대기자 신청(사전 예약) | 2027 Q1 말 |
| 월 ₩4,900가 저항 없는 가격대다 | 2가지 가격 A/B(₩3,900 vs ₩5,900) | 2027 Q2 |
| 워크북 구매자는 구독으로 전환 가능하다 | 구매자 대상 설문·쿠폰 실험 | 2027 Q1 |

## 8. KPI · 실험 체계

### 8.1 북극성 지표 후보

> **"주간 학습 행동 수"** — 3개 서비스에서 의도된 학습 행동(문제 풀이·표현 저장·법구 확인)의 주간 총합.
> 단순 방문이 아니라 *학습 행동*을 측정하는 이유: 방문은 광고로도 만들 수 있지만 학습 행동은 제품력 없이 만들 수 없음.

### 8.2 서비스별 핵심 지표

| 서비스 | 획득 | 참여 | 유지 | 수익 |
| --- | --- | --- | --- | --- |
| toeic | 검색 유입, 첫 문제 풀이 | 주간 풀이 문항 수 | 오답 복습 재방문율 | 유료 전환율 |
| engmon | 주간 유입 | 섹션 완독율, 오디오 재생 | 4주 연속 열람률 | 워크북 구매율 |

### 8.3 측정 가능성 (자체 분석 서버 기준)

| 가능한 것 | 추가 개발이 필요한 것 |

### 8.4 실험 템플릿

```
가설: [무엇을] 하면 [지표]가 [만큼] 오른다.
변수: 변경 단위 1개 (한 실험에 두 가지를 바꾸지 않는다)
지표: 1차 1개 + 관찰 2개
기간: 2~4주 (통계적 유의 대신 실용적 판정 기준 사용)
판정: 확대 / 유지 / 철회 3가지 중 하나로 기록
```
