## 1. 사업자 형태 선택

### 1.1 개인사업자 vs 법인

| 구분 | 개인사업자 | 법인 |
| --- | --- | --- |
| 설립 비용·절차 | 사업자등록만으로 개업 (온라인, 수수료 없음) | 법인설립 등기 + 자본금 + 등기비용 |
| 회계·신고 부담 | 간편장부 가능, 종합소득세 1회 | 복식부기 의무, 법인세·4대보험·결산공시 |
| 세율 구조 | 종합소득 누진세(6~45%) | 법인세(9~24%) + 배당 시 이중과세 |
| 신뢰·거래 | B2C 서비스에는 충분 | 법인 거래·투자·정부사업 참여 시 유리 |
| 손익 | 초기 적자 시 개인 소득과 통산 가능 | 적자 이월결손금 15년 |

**권고**: 현재 MonsterLab는 1인 기반의 무료 서비스 단계이므로 **개인사업자로 시작**하고, 다음 중 하나에 해당하면 법인 전환을 검토합니다.

- 연 매출 1억 원 이상이 지속되거나 외부 투자 유치가 필요해질 때
- 대형 기업(B2B) 계약·정부 지원사업 참여 시 법인 형태가 요구될 때
- 공동 창업자·지분 구조가 생길 때

### 1.2 아직 매출이 없어도 등록하나?

사업자등록 의무는 **"영리를 목적으로 사업을 개시한 때"** 발생하며, 개업일로부터 **20일 이내** 신고합니다(소득세법 제168조). 매출이 아직 없어도:

- 사업을 개시한 것으로 보아 등록 가능하며, 매출이 없는 기간은 **무실적 부가세 신고**를 하면 됩니다.
- 다만, 수익이 전혀 없는 "취미·비영리" 단계라면 등록을 유예해도 법적 문제는 없습니다. **광고 수익·유료화를 시작하는 시점이 등록 기준점**입니다.

## 2. 사업자등록 절차

1. **준비물**: 대표자 신분증, 임대차계약서(사업장이 있는 경우) 또는 주소지 증빙, 인감(전자신고 시 공인인증서)
2. **신청**: 홈택스(www.hometax.go.kr) → 신청/제출 → 사업자등록신청(개인)
   - 사업 개시일을 정확히 기재 (**과거 날짜 소급 신고 불가에 주의** — 개업 예정일을 미리 정할 것)
3. **유형 선택**: 일반과세자 / 간이과세자 / 면세사업자 중 선택 (→ 4장)
4. **업태·업종 기재**: 업태(대분류) + 업종(국세청 업종코드) + 종목(세부 표기) (→ 3장)
5. **처리**: 관할 세무서 서류 검토 후 사업자등록증 발급 (보통 수일)
6. **개인사업자 통신판매업 신고**는 사업자등록 후 별도 신고 (→ 5.4)

> **주의**: 사업자등록증에 적힌 **업종코드는 경비율·간이과세 판단·세제 혜택에 직접 영향**을 줍니다. 잘못 적으면 추후 가산세·경비 부인 리스크가 있으므로 실제 사업 내용과 맞게 선택하고, 애매하면 세무사와 정합니다.

## 3. 업태·업종 선택 (핵심)

### 3.1 개념 정리

- **업태**: 사업의 성격 대분류 (예: 서비스업, 제조업, 도매업, 소매업)
- **업종**: 국세청이 정한 세부 업종코드 (한국표준산업분류를 변형한 별도 코드 체계)
- **종목**: 실제 판매·제공하는 품목의 명칭 (예: 웹 서비스, 온라인 콘텐츠)

### 3.2 MonsterLab 추천 조합

| 항목 | 추천 | 대안 | 설명 |
| --- | --- | --- | --- |
| 업태 | **서비스업(정보통신업)** | — | 소프트웨어·앱 개발 공급업은 정보통신업으로 분류 |
| 주업종 | **응용 소프트웨어 개발 및 공급업 (722000)** | 컴퓨터 프로그래밍 서비스업 (62010) | 자사 서비스(SaaS형 웹앱) 개발·운영이 주 업무이므로 722000이 적합. 외주·주문개발을 병행하면 62010도 검토 |
| 부업종 (engmon) | 전자상거래 소매업 — 디지털 콘텐츠 | 서적·정기간행물 출판업 | 유료 구독·디지털 콘텐츠(워크북 등) 판매가 전자상거래(디지털콘텐츠) 판매에 해당 |
| 부업종 (toeic) | 교육 서비스 관련 업종 | — | 유료화 시점에 등록(면세 요건과 연계 — 4.3) |
| 종목 | 웹 서비스, 온라인 콘텐츠, 소프트웨어 | — | 실제 판매 품목을 기재 |

- **복수 업종 등록 가능** — 주업종은 매출 비중이 가장 큰 것으로, 나머지는 부업종으로 추가합니다.
- **buddha.monster는 무료·무광고**이므로 별도 업종이 필요 없고, 주업종 내 서비스로 운영하면 됩니다.

### 3.3 업종코드 선택의 실제 영향

- **경비율**: 종합소득세 신고 시 단순경비율·기준경비율이 업종별로 다릅니다.
  (예: 컴퓨터 프로그래밍 서비스업(62010) — 단순경비율 75.2%, 기준경비율 23.6%)
- **간이과세 가능 여부**: 업종·매출 규모·사업장 지역에 따라 간이과세가 배제될 수 있습니다(→ 4.2).
- **창업세액감면**: 응용 소프트웨어 개발 및 공급업(722000), 시스템 통합(721000) 등은 중소기업창업 지원법상 창업세액감면 대상 업종입니다.
  (청년 창업 등 요건 충족 시, 수도권과밀억제권역 밖에서 창업하면 감면 한도가 큼)
- **정부 지원사업 자격**: 업종코드가 지원사업 신청 자격 요건에 쓰이는 경우가 많습니다.

> **국세청 업종코드 vs 한국표준산업분류**: 사업자등록은 국세청 업종코드를 사용합니다(2025년 11차 개정에서 응용 소프트웨어 개발 및 공급업이 58222 → 722000으로 변경). 홈택스 신청 화면의 검색 기능으로 최신 코드를 확인하세요.

## 4. 세무 처리

### 4.1 과세 유형 선택: 일반과세 vs 간이과세 vs 면세

| 구분 | 일반과세자 | 간이과세자 | 면세사업자 |
| --- | --- | --- | --- |
| 적용 기준 | 원칙 | 직전연도 공급대가 **1억 400만 원 미만**(2024.7.1. 시행, 기존 8천만 원) + 배제 업종·지역 아님 | 교육용역 등 법정 면세 사업만 |
| 부가세율 | 10% | 업종별 1.5~4% | — |
| 매입세액공제 | 전액 공제 | 공급대가의 0.5%만 공제 | — |
| 세금계산서 | 발행 의무 | 제한적(일부 의무 확대) | — |

**MonsterLab는 일반과세자로 시작하는 것을 권장합니다.** 이유:

1. **SW 개발·공급업은 간이과세가 제한되는 경우가 많습니다.** 간이과세 배제기준(부가가치세법·시행령·국세청 고시)은 업종·매출 규모·사업장 지역(대도시 등 배제 지역)으로 정해지며, IT 개발 업종이 배제 기준에 포함되는 사례가 많습니다. 실무상 SW 사업자는 일반과세로 등록하는 경우가 대다수입니다. **(반드시 등록 시 세무사 확인)**
2. **B2B 거래가 많으면 세금계산서 발행이 필수적**이고 매입세액공제(서버·클라우드·개발도구 등)를 받는 편이 유리합니다.
3. 간이과세는 매입공제가 0.5%에 불과해 매입 비중이 있는 사업에는 불리할 수 있습니다.

### 4.2 간이과세 판단 기준 (참고)

- **금액**: 직전연도 공급대가 합계액 1억 400만 원 미만 (2024.7.1.부터 — 기존 8천만 원에서 상향)
- **배제 업종**(부가가치세법 시행령): 광업·제조업·도매업·부동산매매업·부동산임대업·과세유흥장소, 전문직(변호사·회계사·세무사·변리사·기술사 등)
- **배제 기준**(국세청 고시): 업종별 공급대가 규모 기준 + **사업장 소재지가 배제 지역**(대도시 등)인 경우
- 간이과세 배제 업종을 부업종에 추가하면 자동으로 일반과세자로 전환됩니다.

### 4.3 교육용역 부가세 면세 — toeic.monster 유료화 시 핵심

**원칙**: 교육 관련 매출이 모두 면세는 아닙니다. **주무관청에 허가·인가·등록·신고된 교육기관**이 공급하는 교육용역만 면세입니다(부가가치세법 제26조 제1항 제6호, 시행령 제36조).

| 상황 | 부가세 |
| --- | --- |
| 학원법상 **원격학원 등록** 후 온라인 교육용역 제공 | **면세** (국세청 사전-2023-법규부가-0010 — 플랫폼을 통한 파트너 강사 콘텐츠도 면세 가능) |
| 평생교육법상 **원격평생교육시설 신고** 후 운영규칙에 따른 온라인 강의 | **면세** (국세청 사전-2019-법규해석부가-0244) |
| 등록 없이 일반 사업자가 온라인 강의·학습 콘텐츠 판매 | **과세** (10% 부가세, 세금계산서/현금영수증 처리) |
| 면세 제외 학원(무도학원·자동차학원 등, 시행령 제36조 제2항) | 과세 |

**결론**: toeic.monster 유료화 시 두 갈래 중 선택합니다.

- **A. 교육기관 등록 경로**: 원격학원 등록 또는 원격평생교육시설 신고 → 수강료 면세 → 학습자 부담↓, 단 시설·운영규칙 요건 충족 필요
- **B. 일반 과세 경로**: 등록 없이 디지털 콘텐츠 판매로 운영 → 과세지만 절차 간단

### 4.4 신고·발행 의무

- **부가가치세**: 일반과세자는 1기(1~6월, 7월 신고) · 2기(7~12월, 다음 해 1월 신고). 매출이 없으면 무실적 신고. 직전기 공급대가 1.5억 원 이상이면 예정신고·예정고지.
- **전자세금계산서**: 일반과세자는 공급대가 3만 원 초과 거래에 발행 의무 (홈택스 연계).
- **현금영수증**: 소비자 요청 시 발급 의무 + 의무발행업종 해당 여부 확인.
- **종합소득세**: 다음 해 5월 확정신고 (간편장부 또는 복식부기 — 업종·규모에 따라 복식부기 의무).
- **해외 결제**(Stripe·Paddle 등으로 외화 수취): 매출 인식·환산, 부가세 신고에 포함. 해외 PG 수수료도 매입세액공제 대상인지 확인.

## 5. 서비스별 규제 이슈

### 5.1 toeic.monster (토익 학습 서비스)

- **유료화 시**: 4.3의 교육용역 면세 요건 결정(원격학원/원격평생교육시설 등록 여부). 무신고 교습은 학원법상 과태료 리스크가 있으므로 등록 경로를 명확히.
- **표시광고법**: "합격 보장", "○○점수 보장" 등 효과 과장 표현 주의. 실제 수강생 후기·데이터 기반 표현 사용.
- **소비자보호**: 환불 기준(소비자분쟁해결기준), 자동결제(구독) 시 해지 절차 명시.

### 5.2 engmon.monster (1년 52주 영어 매거진)

- **정기간행물 등록**: 정기간행물 등록은 **의무가 아닌 선택**입니다. 다만 기사 중심의 "인터넷신문"(주 1회 이상 정기 발행 + 일평균 기사 수 요건)에 해당하면 등록 요건이 있으나, engmon은 어휘·문법·퀴즈 중심의 매거진으로 기사성이 낮아 해당 가능성은 낮습니다. 발행 규모가 커지면 등록 이점을 검토.
- **유료 구독 판매**: 통신판매업 신고 + 전자상거래법 준수(→ 5.4).
- **저작권**: 영어 원문(F. Max Müller, 1881 — 공중도메인)은 자유 이용 가능하나, **자체 한국어 번역·해설·구성은 자체 저작물**로 권리 귀속을 명확히(계약서에 위탁 작성 시 저작권 귀속 조항 필수).

### 5.3 buddha.monster (법구경 영·한 대역)

- **무료·무광고·가입 불필요** → 규제 리스크가 가장 낮습니다.
- **저작권**: Müller 번역(공중도메인) + 자체 한국어 번역. 원전(팔리어)은 공중도메인이나 **특정 판본의 주석·해설**은 해당 출처 확인.
- 향후 기부·유료 상품(종이책 등) 추가 시 통신판매업·전자상거래법 규칙 적용.

### 5.4 공통 규제 (모든 사이트)

**통신판매업 신고 (전자상거래법 제12조)**

- 온라인에서 **재화·용역·디지털 콘텐츠를 계속·반복적으로 판매**하면 신고 의무가 있습니다.
- **면제**: 직전년도 통신판매 거래횟수 50회 미만 등(간이과세자 관련 면제 규정 포함) — 초기 소규모 판매는 면제될 수 있으나, 성장 시 신고. 신고는 관할 시·군·구(정부24)에서 하며 PG사 가입 시 구매안전서비스(에스크로) 이용확인증이 필요할 수 있습니다.
- **정보 표시 의무(제13조)**: 사이트에 상호·대표자·주소·연락처·사업자등록번호·통신판매업 신고번호를 표시.
- **청약철회(제17조)**: 디지털 콘텐츠는 "사용·소비로 가치가 현저히 감소"하는 경우 등에 한해 청약철회를 제한할 수 있으나, **제한 사실을 사전에 명확히 고지**해야 합니다. 환불정책을 이용약관에 명시.
